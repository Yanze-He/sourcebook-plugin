# Sourcebook Agent Plugin

The Sourcebook Agent Plugin connects Codex or WorkBuddy to a locally running [Sourcebook Desktop](https://sourcebook.online). It supplies a standard stdio MCP server and a small workflow Skill. Agent changes to a Book remain proposals until the user accepts them in Desktop.

The public installation package is being prepared. The `development` branch contains the current plugin source and test-candidate instructions; this `main` branch is not yet installable. The plugin is versioned independently from Desktop, and a compatible Desktop installation will be required.

This repository contains only plugin distribution files and its MCP source. The Sourcebook landing page is maintained privately and is **not** part of this repository.
