# Sourcebook Agent Plugin installation

The public release is still in testing. This `main` branch does not yet contain an installable MCP helper. Do not register this branch as a working marketplace or report installation success.

For a local test of the unsigned candidate, follow the [development installation guide](https://github.com/Yanze-He/sourcebook-plugin/blob/development/INSTALL.md). The development branch includes macOS Apple silicon and Windows x64 test helpers; it is not a production release.

Before testing, install and open [Sourcebook Desktop](https://sourcebook.online) and enable local Agent access in its settings. If Desktop is missing, direct the user to that site. Report only whether the test installation worked, the plugin version, and any next action.
